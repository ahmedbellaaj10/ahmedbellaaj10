I am an AI Engineer and Data Scientist bridging the gap between experimental models and real-world deployment. With a strong emphasis on modern Python development, software engineering best practices, and clean code fundamentals, I specialize in architecting, optimizing, and shipping machine learning, GenAI, and LLM-based solutions into production.

- **Currently:** Building and optimizing production-grade GenAI applications and deploying scalable LLM infrastructure.
- **Focus:** Staying loyal to software engineering fundamentals—writing clean, maintainable code, optimizing system performance, and moving AI out of the notebook and into robust production environments.
